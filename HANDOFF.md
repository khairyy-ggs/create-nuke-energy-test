# Handoff: Create — Stagg Field (`staggfield`)

## Project and target

A Create addon with an original nuclear-industrial progression centered on a spatial neutron-flux pile, a kinetic fuel cascade, and a Create-powered heat loop. Targets: Minecraft 1.21.1, NeoForge 21.1.228, Java 21, Create 6.0.10-280, Ponder 1.0.82, Flywheel 1.0.6, Registrate MC1.21-1.3.0+67. Gradle wrapper is 8.14.3.

Read `.create-knowledge/index.md`, `research-notes.md`, `atlas.md`, `gotchas.md`, and `STATE.json` before continuing. The full HBM progression/system scan and source links are in `.create-knowledge/research-notes.md`.

## HBM scan: design lessons

HBM's wiki spans workshop and material preparation, early graphite breeding, optional or chemical uranium enrichment, ZIRNOX, PWR/RBMK and research/breeding branches, spent-fuel cooling and reprocessing, radiation protection, large-scale steam/cooling systems, and much later petrochemistry/fusion. Its machine catalog lists 110 machine pages, far broader than one focused addon needs. The wiki identifies its main edition as Minecraft 1.7.10 and marks some pages as outdated, under redesign or deprecated, so use its progression roles as reference and treat exact recipes/stats as edition-specific.

Stagg Field adapts a smaller chain: ore feed prep -> physical pile/scram -> kinetic RPM cascade -> introductory gas-cooled heat loop -> pressurized loop -> higher-risk channel reactor -> advanced breeding/fusion only after the earlier systems are playable. Keep names, code, assets, recipes and setting original. Research source map is in `.create-knowledge/research-notes.md`.

## Build and asset commands

- `gradlew.bat compileJava` — retry source compilation once Maven trust is resolved.
- `gradlew.bat runClient` — load the mod to inspect Create/Flywheel models and gameplay.
- `gradlew.bat runData` — the configured NeoForge data run, if needed.
- `blender -b --factory-startup --python tools/generate_wave13_data.py` — regenerate recipe/worldgen/model JSON.
- `blender -b --factory-startup --python tools/tex.py -- <output-directory>` — write textures using Blender's bundled Python, then copy generated PNGs into `src/main/resources/assets/staggfield/textures/block/`.
- Editable machine scene: `tools/blender/StaggFieldModels.blend`; OBJ export script: `tools/model_blender.py`.
